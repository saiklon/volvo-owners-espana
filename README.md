# Volvo Owners España
Web de presentación de una comunidad independiente de propietarios Volvo en España.

## Publicación con GitHub Pages
1. Abre Settings → Pages en este repositorio.
2. En Build and deployment selecciona Deploy from a branch.
3. Branch: main. Folder: / (root). Pulsa Save.
4. La URL será https://saiklon.github.io/volvo-owners-espana/

## Estado de esta publicación
La página de presentación está en index.html. Esta publicación inicial no incluye todavía un servicio de registro operativo. El formulario, autenticación, fotografías privadas y administración requieren configurar Supabase y desplegar el cliente conectado.

## Próximos pasos
- Crear proyecto Supabase.
- Ejecutar supabase/schema.sql en SQL Editor.
- Configurar Auth, políticas RLS, bucket privado y cuenta administradora.
- Completar y revisar aviso de privacidad antes de aceptar datos reales.

Nunca publicar una clave service_role en el navegador o en GitHub.

## Marca
Volvo Owners España es una comunidad independiente, no afiliada, patrocinada ni respaldada por Volvo Cars. No utiliza el logotipo oficial.
