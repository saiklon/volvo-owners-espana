# Volvo Owners España

Comunidad independiente de propietarios Volvo en España.

Primera versión web en preparación. Incluye registro de propietarios, ficha del vehículo, fotografía obligatoria y validación administrativa mediante Supabase. Consulta `supabase/schema.sql` y las instrucciones de configuración antes de activar el registro.

No afiliada, patrocinada ni respaldada por Volvo Cars.
